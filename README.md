## Featured projects

**[IoT Signal Ingestion Pipeline](https://github.com/amirhoseinhoseinpoor/Backend-developer-assessment)**
A message-driven backend: a producer service publishes device location and speed
readings to RabbitMQ, and a NestJS consumer stores them in MongoDB and serves them
through a REST API. Messages are acknowledged only after they are saved.
`NestJS` `RabbitMQ` `MongoDB` `Docker`

**[Sitenura](https://github.com/amirhoseinhoseinpoor/sitenura)** (in progress)
A platform for building websites without code: a planner model turns the user's
intent into small ordered tasks and an executor model carries them out. TypeScript
monorepo with a layered NestJS API, a Next.js front end, shared Zod schemas as the
API contract, PostgreSQL through Prisma, and CI.
`Next.js` `NestJS` `Prisma` `PostgreSQL` `Turborepo`

**E-commerce platform for Azar Hologram** (private, company code)
Customer-facing web store, backend service and admin panel that I have built and
maintained for the company.
